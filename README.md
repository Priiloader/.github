## Quick Start

1. **Prepare the environment:** Ensure the Homebrew Channel is installed and working. The Priiloader project recommends Homebrew Channel 1.0.7 or newer.
2. **Prepare installation files:** Download the Priiloader release package and copy the required files to an SD card or compatible USB storage device. Keep `hacks_hash.ini` in the expected application directory when using System Menu hacks.
3. **Run the installer:** Launch the Priiloader installer through the Homebrew Channel and follow its on-screen instructions. Read the official documentation before confirming installation.

## Key Features

### Pre-System Menu Environment
- Loads before the Nintendo Wii System Menu.
- Provides an alternative entry point when certain System Menu failures occur.
- Can launch supported applications and system titles.
- Supports configurable autoboot behavior.

### Recovery and Boot Management
- Provides recovery options for some user-level brick conditions.
- Supports launching BootMii IOS from its menu and autoboot configuration.
- Can launch DOL and ELF binaries.
- Includes options for selecting the startup target.

### System Menu Patches
- Provides configurable System Menu hacks.
- Supports update-blocking patches.
- Includes region-related patch options.
- Supports Wiimmfi-related System Menu patching.

### Platform and Device Support
- Includes support for Wii, vWii, and Wii Mini.
- Can load Wii and GameCube discs through supported menu functionality.
- Supports SD and USB device access.
- Includes configurable device-priority behavior.

## FAQ

**1. What is Priiloader?**

Priiloader is a homebrew application that loads before the Wii System Menu. It provides boot configuration, application launching, System Menu patches, and recovery options for certain user-level brick conditions.

**2. Does Priiloader support Wii U vWii?**

Yes. Priiloader 0.10.0 added vWii compatibility. The vWii installation and launch workflow differs from the original Wii procedure.

**3. Does Priiloader support Wii Mini?**

The project includes Wii Mini support. Some features and navigation methods differ from standard Wii hardware.

**4. Can Priiloader recover every bricked Wii?**

No. Its recovery capabilities apply to certain user-level brick conditions. It cannot recover a console when critical components such as the System Menu IOS are damaged.

**5. Where can I find the latest release?**

Use the official Priiloader GitHub Releases page for the installer, release notes, and related files.
